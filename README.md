In this bachelor thesis there was executed a mapping of breeding birds and of vegetation on the nature protection area "Ebenberg" in Landau in der Pfalz (Germany).
The data got introduced to QGIS first, where also a grid of the area of investigation got produced. For each cell of the grid was analyzed which breeding bird species is abundant using QGIS.
The result of this analysis got saved in a table and entered in R. With a multivariat analysis it got tested, if there is a significant zusammenhang of breeding bird species in specifical types of vegetation.
For this the multivariat analysis xx got used.
